브라우저 rAF · 측정 대기

기본은 1.5× 균형입니다. 버튼을 누르면 2× 고선명 → 1× 저부하 → 1.5× 균형으로 바뀝니다. 1× 대비 처리 픽셀은 1.5×에서 약 2.25배, 2×에서 4배이므로 FPS가 낮아질 수 있어요. 끊기면 1×를 선택해 주세요. 화면 크기와 터치 위치는 같습니다. 새로 열면 1.5×로 시작하며, 게임 준비 전에는 안전하게 1×를 사용합니다.

CPU는 스크립트 구간별 평활값입니다. 그리기는 명령 생성 시간이며 GPU 시간은 측정하지 않습니다. HUD는 프레임당 값이고, 메인 기타는 계산·HUD·진단 발행을 제외합니다. 엔진 내부 처리·브라우저 대기 등은 포함하지 않아 합계가 전체 프레임 시간은 아닙니다. 렌더 횟수는 UI를 포함한 2D 화면의 최근 렌더 프레임입니다.

p95·p99는 각각 95%·99%의 프레임이 이 값 이내라는 뜻입니다. 최대값이 크게 튀면 순간 끊김을 의심할 수 있어요.

게임 FPS는 실제 Godot 콜백 간격의 평활값입니다. 화면에 보이는 동안 긴 멈춤도 포함하고, 백그라운드 전환·복귀 간격은 제외합니다. rAF는 브라우저 콜백 간격이며 실제 패널 주사율(Hz)은 확인할 수 없습니다. 이 창이 열려 있을 때만 최근 최대 2초를 추가 측정합니다. 계산은 60Hz, 화면은 보간합니다. 진단값은 기기 안에서만 표시합니다.
