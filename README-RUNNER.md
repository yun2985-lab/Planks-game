# 벨켓 런 v06

runner.html: 모바일 웹 게임. 자동 전진, 좌측 하단 아날로그 조이스틱/드래그 또는 A/D·방향키. v07 기본은 캐릭터가 보이는 높은 추적 시점이며, 시점 버튼으로 1인칭 선택. 지상 → 구멍 → 수직 낙하 → 지하 동굴 → 도착.

혼자 플레이 또는 방 만들기. 방장은 코드를 공유하고 참가자는 방 참가에서 입력합니다. 방장 포함 최대 5명, 각 참가자가 자신의 캐릭터를 조작하고 개인 카메라를 사용합니다. 방장이 시작/일시정지를 관리하며 전경에 켜 두어야 합니다.

온라인 기능은 베타입니다. PeerJS Cloud는 연결 신호를 전달하고 실제 게임 상태는 방장 휴대폰에서 WebRTC로 전달합니다. 일부 NAT·통신망은 TURN 중계가 필요하지만 이 버전에는 별도 TURN 설정이 없습니다. 연결 실패는 오류 안내를 표시합니다. 방장이 종료하면 방이 종료됩니다. 네이티브 APK가 아닌 브라우저 실행 버전입니다.

검증: 1명/5명 시뮬레이션의 지상·낙하·지하 완주, 정원 제한, 입력 범위, 일시정지. 모의 통신으로 5명 정원·6번째 거절·독립 입력·상태 동기화·공동 정지·퇴장 검증. 소프트웨어 WebGL에서 실제 렌더러의 단계별 화면과 시점 전환 검증. 로컬 실제 WebRTC 테스트는 offer/answer까지 교환했지만 ICE 연결이 열리지 않았으므로 휴대폰 5대 실제 연결과 모바일 성능은 미검증입니다.

기존 버전: plinko-3d-v05.html. 원래 index.html 및 plinko-game.html 유지.

라이선스: Three.js 기존 번들, PeerJS 번들 및 vendor/PEERJS-LICENSE.txt.

## v07 그래픽
참고 이미지에 맞춘 지상·동굴 개인 추적 카메라, 좁고 굽은 모래 코스, 매끄러운 보라색 가장자리, 광택 캐릭터와 둥근 꼬리, 부드러운 접지 그림자, 식물 군집, 낙하 벽면·속도 선, 수정 군집·동굴 아치·전방 안내 화살표를 적용했습니다. 외부 이미지 없이 절차적 3D 메시와 조명을 사용합니다. 참고 이미지의 사진 수준 조명, 피사계 심도와 모션 블러를 동일하게 재현했다는 의미는 아닙니다. 소프트웨어 WebGL에서 단계별 렌더링과 시점 전환 오류 없음; 기존 1명/5명 시뮬레이션 및 모의 통신 테스트 통과. 실제 모바일 FPS 및 다섯 휴대폰 WebRTC 접속은 미검증 상태입니다.

## v08 낙하와 터치 조작
구멍 중심까지 공중에서 진행하던 진입 조건을 구멍 앞쪽으로 옮겼습니다. 낙하 초기 수직 속도는 17 units/s이며 2.7초에 64 units 깊이에 도달합니다. 낙하·착지 시 카메라의 즉시 이동을 제거하고 위치와 바라보는 점을 각각 보간합니다. 진입 동안 지상과 낙하 통로를 함께 보이며 카메라가 통로 벽 밖으로 나가지 않도록 제한합니다. 시작 화면에서 렌더러 shader compile을 수행해 첫 장면 전환의 준비 작업을 줄입니다.
좌측 하단 조이스틱은 4px dead zone, 최대 40px 이동, 비례 좌우 입력이며 release/cancel/lost capture/blur 시 중앙 복귀와 입력 0을 처리합니다. 키보드와 화면 드래그도 유지합니다. 캐릭터 광택의 거칠기와 모래 색을 조정하고 횃불의 발광 색을 보강했습니다.
검증: 소프트웨어 WebGL에서 진입 다음 프레임 하강 >0.2 units, 초기 14프레임 카메라 프레임간 최대 이동 약0.535 units, 낙하 후 지하 도달; 실제 포인터 드래그 36px 입력0.889 및 release 입력0; 단계별 렌더링·시점 전환 JS 오류 없음. 1/5명 완주 및 모의 통신 테스트 통과. 실제 휴대폰 프레임 지연 해소 및 5대 온라인 접속은 미검증입니다. 온라인 방은 이전 클라이언트와 다른 물리 모델을 섞지 않도록 v08 식별자를 사용합니다.
